# Is It Relay?

A community-built address detector for Relay Protocol infrastructure and deposit-address requests.

## Project status

This project is discontinued and no longer maintained. Relay API changes mean its data is no longer available through sustainable public read-only access. Keeping live lookups would require hosting a server to provide an API key, which isn't sustainable for this project.

Relay's [Requests v3 migration guide](https://docs.relay.link/references/api/api_guides/migrating-to-requests-v3) explains the API changes, API key requirement, and Requests v2 retirement timeline.

The website remains online as a static demo. It no longer checks addresses against Relay's live APIs.

[Open the demo](https://warengonzaga.github.io/is-it-relay/)
